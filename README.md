Desenvolvi um sistema de delivery/restaurante que modela o fluxo completo de um pedido: o cliente escolhe itens do cardápio do restaurante e realiza os pedidos.
O entregador é responsável por levar o pedido até o cliente; após a entrega o cliente pode registrar aavaliação  sobre o pedido e entrega. O cardápio sempre está
vinculado a um restaurante específico e o pedido conecta : clientes, restaurante e os itens escolhidos.

Stacks utilizadas: MySQL, Brmodelo.
